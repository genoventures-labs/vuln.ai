# TALOS Distributed Tool Mesh (DTM) & Lab Handoff

## Overview
Implemented a decentralized tool discovery and JIT crafting system for the T.A.L.O.S. substrate. Nodes can now share capabilities via a federated "Ping and Pass" mesh and autonomously create missing tools using a dedicated "Lab" module powered by Ollama.

## Core Components

### 1. Mesh Protocol (`internal/mesh`)
- **Discovery**: Nodes broadcast tool requirements (semantic queries) to neighbors.
- **Trust**: Secured via `MESH_TRUST_TOKEN` (static shared secret for mesh nodes).
- **Endpoint**: `POST /mesh/query` - Allows neighbors to search the local tool registry.
- **Neighbor Registry**: Active neighbors are read from the `mesh_neighbor` table; falls back to `MESH_NEIGHBORS` env if no active records.
- **Roster API**: `GET /mesh/neighbors` returns a simple list of known neighbors (public).
- **Admin API**: `POST /mesh/neighbors` and `POST/DELETE /mesh/neighbors/{id}` manage neighbor entries (admin).
- **Registration API**: `POST /mesh/register` accepts `{ url, label }`, inserts if missing, and returns the full neighbor roster.

### 2. Lab - JIT Tool Crafter (`internal/lab`)
- **Engine**: Uses `qwen2.5-coder:7b` (via Ollama) to generate code.
- **Verification**: Validates AST + runs generated code in the Lab sandbox; supports `docker` or local `subprocess` modes (default `subprocess`).
- **Endpoint**: `POST /lab/craft` - Manually triggers JIT tool creation.

### 3. Unified Tool Search (`/tools/search`)
Orchestrates the tool acquisition loop:
1. **Local Search**: Queries the SQLAlchemy `tool` table and uses embeddings if available, with text-match fallback.
2. **Mesh Search**: Parallel broadcast to neighbor URLs from `mesh_neighbor` (active only), falling back to `MESH_NEIGHBORS`.
3. **Lab (JIT)**: (Optional) If nothing found and Lab is enabled, crafts the tool on-the-fly.

## Configuration Requirements (.env)

```bash
# Mesh Setup
MESH_ENABLED=true
MESH_NEIGHBORS=http://node1:8081,http://node2:8081
MESH_TRUST_TOKEN=your_secure_mesh_token
MESH_QUERY_TIMEOUT=8
MESH_MAX_NEIGHBORS=25
MESH_BOOTSTRAP_URL=http://bootstrap-node:8080
MESH_SELF_URL=http://this-node:8080

# Lab Setup
LAB_ENABLED=true
OLLAMA_MODEL_CODE=qwen2.5-coder:7b
OLLAMA_OPENAI_BASE_URL=http://localhost:11434/v1
LAB_SANDBOX_MODE=subprocess  # or docker
LAB_SANDBOX_DOCKER_IMAGE=python:3.11-slim
```

## Bootstrap Notes
- **Connectivity**: `MESH_BOOTSTRAP_URL` must be reachable from the node at startup; if public hairpin/NAT is blocked, use an internal address (e.g., Docker network hostname).
- **Self Address**: `MESH_SELF_URL` is what gets stored and shared with peers; set it to the public address you want other nodes to use.
- **Loop Safety**: Bootstrap to a different node (not self) to avoid registration loops.
